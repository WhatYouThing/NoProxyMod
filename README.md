# NoProxyMod

- Addon for [NoFrills](https://github.com/WhatYouThing/NoFrills) which
  implements [NoProxy](https://whatyouth.ing/noproxy/) service functionality.

## Usage

- Download the latest [release](https://github.com/WhatYouThing/NoProxyMod/releases) appropriate to your Minecraft
  version.
- Configure the mod from the multiplayer screen.
